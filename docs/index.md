# TutorBroPro

[![CI Status](https://github.com/AY2627S1-CS2103T-F11-4/tp/workflows/Java%20CI/badge.svg)](https://github.com/AY2627S1-CS2103T-F11-4/tp/actions)

![Ui](images/Ui.png)

**TutorBroPro is a desktop app for freelance private tutors to manage their students and lesson records.** While it has a GUI, most of the user interactions happen using a CLI (Command Line Interface).

* If you are interested in using TutorBroPro, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing TutorBroPro, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
